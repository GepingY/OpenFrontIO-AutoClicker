# OpenFrontIO-AutoClicker
"OpenFront.io AutoClicker" is a script that is made to carry out actions in OpenFrontIO faster, for example in a 50x Gold "Nuke War" custom game, players often run into the issue where despite sufficient resources, player is simply unable to launch nuke fast enough to penetrate enemy air defense(Sam)

## How to Use

Copy the content of `Main.js` and save it as a bookmark in your browser. When in a game, simply click the bookmark to activate it.

Hold the corresponding key and click where you want the building to be built for a single execution. Holding the key and rapidly clicking allows you to build a large amount within seconds.

| Key (Hold) | Action |
| :---: | :--- |
| `x` | Launch 50 **Nuke** |
| `z` | Build/Upgrade 100 **Port** |
| `v` | Build/Upgrade 100 **Sam** |
| `b` | Build/Upgrade 100 **Silo** |

## Structure of Code
Code for individual action is saved in the folder /src

Main.js is a combined script for which you only need to execute once to gain all the function provided by the scripts in /src
